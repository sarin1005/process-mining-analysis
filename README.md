# Process-mining-analysis
University group project using process mining to analyse a hospital billing workflow, identify bottlenecks and rework, and propose data-driven process improvements.

Overview:
This repository showcases a university group project completed as part of a Process Mining and Analysis unit at The University of Western Australia.

The project applied process mining techniques to analyse real-world event log data, identify inefficiencies in business processes, evaluate process conformance, and propose recommendations for process improvement.

Note: This repository contains presentation materials only. Datasets and some supporting files are not included due to copyright and academic integrity considerations.

Objectives:
- Analyse business process event logs
- Discover actual process flows
- Compare discovered processes with expected models
- Identify bottlenecks and deviations
- Recommend process improvements
